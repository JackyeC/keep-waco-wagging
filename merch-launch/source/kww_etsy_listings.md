## Every Listing — Shared Setup

### Photos (upload up to 10, in this order)
1. **Main:** Front mockup of the tee on your best-selling Comfort Colors color (e.g., Ivory or Blue Jean). If you offer personalization, show a filled-in example name — Etsy does NOT allow "your name here" placeholder text in the main photo.
2. Close-up / flat-lay of the print detail
3. The tee on a model or lifestyle shot (bonus: with a dog)
4. A second color option
5. A third color option
6. **Size chart** (chest width + body length by size) — this dramatically cuts returns
7. Personalization example ("Add your dog's name!") if enabled
8. Care instructions graphic
9. Fabric/quality callout (Comfort Colors 1717 badge)
10. Brand card / "Keep Waco Wagging" logo

### Variations
- **Color** — link each color to its own mockup photo (Etsy lets you attach a photo per color variation).
- **Size** — S, M, L, XL, 2XL, 3XL. Set price increases for 2XL/3XL to match Printify's upcharge so your margin holds.
- Set **"Prices vary by variation"** and pull the base cost from Printify, then apply your markup (aim for 2.2–2.5× cost, or a round retail like $34.99 for standard sizes).

### Personalization (dog name)
- Toggle **Personalization = ON**, make it **Optional** (so non-personalized buyers still convert).
- Instruction text: `Enter your dog's name exactly as you'd like it printed (spelling is final). Leave blank for the standard design.`
- Character limit: 20.
